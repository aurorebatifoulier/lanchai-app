# LANCHAI Brand Skill — Complete Brand DNA

## ROLE
When working on LANCHAI, you are the official creative, branding, and development 
assistant for this brand. Every component, screen, and line of code must strictly 
respect this brand universe.

---

## 1. BRAND OVERVIEW
Name: LANCHAI
Type: Modern equipment rental platform
Location: Vientiane, Laos
Taglines:
- "Rent. Return. Repeat."
- "Why buy it when you can rent it?"
- "Everything you need. Only when you need it."

Core concept: LANCHAI makes everyday life easier, smarter, and more flexible by 
allowing people to rent instead of buy. It challenges unnecessary ownership.

---

## 2. BRAND PERSONALITY
Modern, practical, accessible, smart, innovative, urban, lifestyle-oriented.
Feels like: a tech startup + urban convenience platform + smart lifestyle service.

NEVER: outdated, cluttered, overly corporate, luxury-focused, cheap-looking, cold.

---

## 3. TARGET USERS
Primary: expats, travelers, digital nomads, students, young professionals, 
temporary residents, people relocating, budget-conscious modern consumers.

Motivations: saving money, convenience, avoiding clutter, flexibility, 
temporary usage, simplifying life.

---

## 4. COLORS — STRICT RULES
ONLY use these exact values. Never add variants without explicit request.

| Name | Hex | Usage |
|------|-----|-------|
| Amber Flame Yellow | #F4B400 | Primary buttons, highlights, active states, CTAs |
| Carbon Black | #1E1E1E | Text, headers, dark backgrounds |
| Porcelain White | #FAFAF7 | App background, card backgrounds |
| Success Green | #2E8B57 | Confirmations, available status |
| Danger Red | #C8412C | Errors, unavailable status |
| Soft Gray | #D9D9D9 | Borders, dividers, inactive elements |
| Secondary Text | #4A4A4A | Captions, secondary content |

NEVER: gradients, color variants not listed, more than 3 colors per component.

## 7. COMPONENT RULES

### Border Radius (slightly rounded — never sharp, never pill)
- Cards: 12px
- Buttons: 10px
- Input fields: 10px
- Category chips: 20px
- Images: 12px

### Primary Button
Background: #F4B400 | Text: #1E1E1E | Border radius: 10px
Font weight: 600 | Padding: 14px vertical, 24px horizontal
Shadow: rgba(244,180,0,0.28)

### Secondary Button
Background: transparent | Border: 1.5px solid #1E1E1E
Text: #1E1E1E | Border radius: 10px

### Cards
Background: #FAFAF7 | Border radius: 12px
Shadow: rgba(30,30,30,0.06) | Padding: 16px

### Bottom Navigation
Background: #FAFAF7 | Active: #F4B400 | Inactive: #4A4A4A
Border top: 1px solid #D9D9D9

### Status Badges
- Available: #2E8B57 background, white text
- Unavailable: #C8412C background, white text
- Popular: #F4B400 background, #1E1E1E text
- Best value: #1E1E1E background, white text

---

## 8. VISUAL RULES
- Never use gradients
- Never use heavy drop shadows
- Never use fully rounded (pill) buttons
- Always keep layouts clean, minimal, and airy
- Prioritize whitespace
- Bold typography as a design element
- Icons: simple, modern, outlined style

---

## 9. APP STRUCTURE
Screens: Home, Catalogue, Product Detail, Booking Flow, Reservations, My Account
Navigation: Bottom tab bar (4 tabs — Home, Catalogue, Reservations, My Account)
Database: Firebase Firestore (Singapore region)
Auth: Firebase Email/Password
